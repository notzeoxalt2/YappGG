YappGG microphone setup

YappGG controls presets, EQ and real ClearCast with the included local audio engine.

  1. Install YappGG. Its audio engine and signed microphone driver components are included; the GG app is not required.
  2. Open YappGG and select your physical microphone. Windows now names its existing capture endpoint YappGG Microphone, with YappGG Audio as its adapter label.
  3. Choose YappGG Microphone in Discord Input Device. Reopen Discord if it cached the old name. The rename needs no PC restart.
  4. Keep Windows and Discord output on your physical headphones. Do not select the virtual microphone as an output.
  5. Enable ClearCast AI noise reduction in YappGG and use TEST to record the result.

Enhance Discord mic settings

Check Enhance Discord mic settings while installing, or open YappGG Settings → Discord → Apply & restart Discord. It disables Discord noise suppression, Krisp noise cancellation, automatic gain, automatic sensitivity and Krisp voice detection. It sets the manual threshold to −70 dB. Discord restarts; an active call disconnects. Your other settings, devices, volumes, mute state and push-to-talk shortcuts are preserved.

Revert & restart Discord restores your previous voice filters and sensitivity. Repeated enhancement keeps the original restore point. If Discord is not installed or its storage format is unsupported, setup reports the problem instead of claiming success.

Clean in recordings, but words cut off in Discord?

Discord can apply a second noise filter and voice gate to an already cleaned microphone. In Discord → User Settings → Voice & Video:

  1. Input Device: choose YappGG Microphone explicitly. Output stays on your headphones.
  2. Noise Suppression: None. Let ClearCast do the cleanup once.
  3. Automatic Gain Control: off, so Discord does not change your processed volume.
  4. Automatically determine input sensitivity: off. While speaking softly, move the manual threshold below the quietest speech on the meter. Start around −70 dB, then adjust using your own meter.
  5. If using headphones, try Echo Cancellation off as well. Speakers may still need echo cancellation.
  6. Compare Discord Mic Test with a friend hearing you in a real call. If words still disappear, briefly test Push to Talk while holding the key for the entire sentence. If this fixes it, adjust the Voice Activity threshold further.

Apply setup changes the Windows default microphone only. Use the separate Enhance Discord mic settings option to change the saved desktop voice-processing settings. You can also change them manually using the steps above.

Screen sharing and mute

The direct engine does not copy your microphone to speakers. If GG is already running, compatibility mode excludes the mic from its streaming and monitoring mixes. Use YappGG microphone mute for global processed-mic mute. Screen-share protection automatically mutes Discord’s extra render session on the virtual microphone, matching the Windows mixer workaround. Keep it enabled in Settings.

Ask a friend to check silence while sharing with YappGG muted. Prefer sharing specific application audio. Whole-system audio capture or Windows Listen to this device can introduce another path.

Boost and desktop audio

Settings includes microphone boost with a 0 to +36 dB slider and numeric entry up to +120 dB and a switch to block apps routed into the virtual mic. Headphones prevent speaker audio reaching the physical mic; this switch cannot cancel sound recorded acoustically.

Aftereffects

Enable Trolling features in Settings and select a Second effect. Your base preset and ClearCast run first, then the effect and microphone boost. No second cleanup stage follows the effect. High boost clips audio; very loud audio may get you kicked or banned from Discord servers. Turn the feature off to restore your clean base voice.

Fun presets

Crappy Voice, Loud Mess and Busted Radio deliberately distort the voice. Telephone, Tin Can and Megaphone reduce fidelity with local audio effects. Select Clear Voice or Deep Voice to return to the clean native ClearCast processing.

Internal feed

Windows also lists YappGG Microphone Feed as an output because the signed virtual driver needs it to receive processed audio. Keep your headphones or speakers selected as sound output. Hiding that feed currently stops microphone transport.

Installed components

YappGG installs the included signed Sonar audio components if needed. The GG app is not required. No VB-CABLE or unsigned custom driver is installed.
